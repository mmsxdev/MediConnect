## Orientações gerais

- Não criar tecnologia apenas para aumentar a complexidade do projeto.
- Não escolher uma arquitetura somente porque ela é mais moderna.
- Não copiar justificativas prontas.
- Não atribuir notas sem explicar o motivo.
- Não é obrigatório realizar uma migração arquitetural nesta atividade.
- Quando houver alteração de código, compile o projeto e execute os testes existentes.
- Utilize evidências concretas do próprio projeto.
