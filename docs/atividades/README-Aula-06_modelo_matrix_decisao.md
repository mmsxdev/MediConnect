# Modelo — Matriz de Decisão Arquitetural

## Como utilizar

1. Escolha pelo menos **3 alternativas arquiteturais**.
2. Defina critérios relevantes para o projeto.
3. Atribua um **peso** para cada critério.
4. Atribua uma **nota** para cada alternativa.
5. Calcule `Peso × Nota`.
6. Some os resultados de cada alternativa.
7. Justifique todas as notas no arquivo `MODELO-JUSTIFICATIVAS-NOTAS.md`.

---

## Escala sugerida para os pesos

| Peso | Significado |
|---:|---|
| 1 | Baixa importância para o projeto |
| 2 | Importância média |
| 3 | Alta importância |

---

## Escala sugerida para as notas

| Nota | Significado |
|---:|---|
| 1 | Atende fracamente ao critério |
| 2 | Atende parcialmente |
| 3 | Atende de forma adequada |
| 4 | Atende bem |
| 5 | Atende muito bem |

### Observação

A maior pontuação **não determina automaticamente a decisão final**.

O grupo deve considerar também:

- custos;
- riscos;
- complexidade;
- limitações;
- contexto do projeto;
- trade-offs.

A decisão final deve ser registrada e justificada na atividade principal.
