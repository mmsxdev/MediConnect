# Modelo — Justificativas das Notas da Matriz

## Objetivo

Registrar a justificativa de cada nota atribuída na matriz de decisão arquitetural.

> Não utilize justificativas genéricas ou copiadas. A justificativa deve estar relacionada ao projeto analisado.

---

## Regra

Para cada nota da matriz, responda:

1. **Qual critério está sendo avaliado?**
2. **Qual alternativa está sendo avaliada?**
3. **Qual nota foi atribuída?**
4. **Por que essa nota foi atribuída?**
5. **Qual evidência do projeto sustenta a justificativa?**

## O que deve ser considerado uma evidência

Podem ser utilizados, por exemplo:

- classe;
- pacote;
- módulo;
- serviço;
- interface;
- repositório;
- integração externa;
- configuração;
- teste;
- requisito documentado;
- dependência entre componentes;
- fluxo atual do sistema;
- limitação identificada no projeto.

---

## Não fazer

Não utilizar textos como:

- "é melhor";
- "é mais moderno";
- "é mais rápido";
- "é mais seguro";
- "é mais fácil";
- "é mais escalável";

sem explicar **por quê** e sem relacionar a afirmação ao projeto.
