# Requisitos atualizados

## Funcionais

- RF01 — Cadastrar pacientes.
- RF02 — Agendar consultas para pacientes cadastrados.
- RF03 — Solicitar exames e consultar autorização do convênio.
- RF04 — Enviar exame autorizado ao laboratório externo.
- RF05 — Registrar internações.
- RF06 — Notificar pacientes sobre consultas e exames.
- RF07 — Registrar eventos relevantes para observadores de auditoria/notificação.
- RF08 — Permitir definição de prioridade para tipos de atendimento.

## Não funcionais a detalhar

- RNF01 — Proteger dados pessoais e informações de saúde.
- RNF02 — Manter rastreabilidade das operações relevantes.
- RNF03 — Tratar indisponibilidade ou falha de sistemas parceiros.
- RNF04 — Definir critérios mensuráveis de desempenho e disponibilidade.

Os critérios de aceitação devem ser refinados pelo grupo conforme as aulas.
